조작

서버

같은 오리진이면 소켓 URL도 여기서 유도한다. http → ws, https → wss.

① 방

조회는 인증이 필요 없다. 참가하면 슬롯이 PENDING으로 잡히고 토큰이 나온다.

② 프로필

선택하지 않으면 서버가 남은 것 중 무작위로 배정한다.

확정하면 ACTIVE가 되고 그때 member:joined가 다른 창에 뜬다.

③ 소켓

연결 뒤 3초 안에 conn:auth를 보내지 않으면 서버가 4408로 닫는다.

아직 붙지 않은 이벤트는 game.invalid_action으로 돌아온다. 연결은 유지된다.

④ 이탈

1000만 즉시 확정이다. 그 밖의 종료는 의심(UNSTABLE)을 거쳐 유예 만료 시 확정된다 — 참가자 30초 · 방장 60초. 1001은 브라우저가 페이지를 떠난 경우이며, 클라이언트가 페이지 숨김·새로고침에 1000을 보내면 안 되는 이유다. 방장이 나가면 방이 삭제되고 남은 창은 room:closed 뒤 4410으로 밀려난다.

빠른 실행

방 생성/참가 → 프로필 확정 → 소켓 연결까지 이어서 실행한다.
