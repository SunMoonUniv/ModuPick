# ModuPick — 실행 방법

팀장·발표자·벌칙을 미니게임으로 뽑는 실시간 웹앱입니다. 백엔드가 나오기 전이라 `local-server/`가 임시 서버 역할을 합니다.

## 처음 한 번

```bash
npm install
```

`local-server`의 의존성(express, socket.io, cors)도 루트 `package.json`에 있어 이 한 번으로 끝납니다.

## 실행 (터미널 2개)

```bash
npm run server   # 임시 서버 — 4000 포트
npm run dev      # 프론트 — 5173 포트
```

브라우저에서 `http://localhost:5173` 접속.

## 같은 네트워크의 여러 PC에서 플레이

1. 방장 PC 한 대에서만 위 두 명령을 **같이** 실행합니다.
2. 방장 PC의 LAN IP를 확인합니다 (`npm run dev`가 출력하는 `Network:` 주소).
3. 방장 포함 모든 참가자가 `http://<방장 IP>:5173` 으로 접속합니다.

프론트는 항상 "페이지를 연 호스트의 4000 포트"를 서버로 씁니다(`src/api/endpoint.ts`). 그래서 방장 PC의 IP로 접속하기만 하면 별도 설정이 필요 없습니다.

> Windows 방화벽이 처음 실행 시 Node의 네트워크 접근을 물어보면 **허용**해야 다른 PC에서 접속됩니다.

다른 주소의 서버를 쓰려면 `.env.local`에 `VITE_SERVER_URL=http://호스트:포트`를 넣으면 됩니다.

## 알아둘 동작

- **새로고침 = 퇴장.** 재접속 경로가 없는 프로토콜이라 새로고침하면 방에서 빠집니다(경고창이 뜹니다).
- **방장이 나가면 방이 사라집니다.** 방장 위임이 없습니다.
- **10분 무활동이면 방이 만료**됩니다.
- 임시 서버는 메모리에만 상태를 두므로 서버를 재시작하면 모든 방이 사라집니다.
- 채팅 이력은 서버가 저장하지 않고 브라우저 로컬스토리지에만 남습니다.
