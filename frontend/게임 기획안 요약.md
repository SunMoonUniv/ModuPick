# ModuPick 미니게임 상세 규칙 요약

> 원본: `게임 기획안.md`

## 1. 공통 진행 규칙
- 참여: 최소 2명 ~ 최대 10명. 눈치게임·익명 저격·킹메이커는 **3명 이상** 필요.
- 권한: 방장만 게임 종류·옵션·시작을 조작. 팀원은 열람만.
- 시작 시점 참가자 명단을 그 회차 참가자로 고정 — 진행 중 방은 입장 불가.
- 시작 절차: 게임 선택 → 옵션 설정 → 전원 준비완료 확인 → 방장이 시작 → **전원 화면에 3초 가이드** → 가이드 사라지면 서버 기준 시작. 가이드는 게임 화면에서 다시 열람 가능.
- 판정은 항상 서버 기준(시각·난수 시드 포함), 클라이언트 애니메이션은 표현일 뿐. 동일 입력 재전송은 1회만 처리, 종료된 회차 입력은 무시.
- 종료: 서버가 결과 확정 → 게임 화면에서 결과 연출 → 공개 후 3초 뒤 결과 화면 이동 → 결과 이미지 저장 가능 → 방장이 `다시 하기`/`대기방 복귀` 선택. 다시 하기는 기존 설정 그대로 재시작.
- 동점자 재투표·눈치게임 전원탈락·다시 하기 재시작 시에는 가이드 재표시 안 함.
- 재접속 불가: 게임 중 이탈 후 재접속하면 새 참가자로 간주.

## 2. Game 1 · 운명의 룰렛
- 목적: 팀장·발표자 등 1명 무작위 선정.
- 설정: 결과 항목(역할·벌칙 직접 입력).
- 진행: 참가자를 룰렛 조각(균등 확률)으로 배치 → 방장이 PICK → 서버가 시드+당첨자 생성 → 전원 동일 회전 애니메이션 → 3~5초 후 공개.
- 판정: 애니메이션은 연출용, 결과는 서버 결정. 도중 퇴장자 있어도 시작 시 확정 후보·결과 유지.
- 결과 데이터: 후보 목록, 결과 항목, 서버 시드.

## 3. Game 2 · 랜덤 사다리
- 목적: 참가자 전원에게 역할/벌칙 일괄 배분.
- 설정: 결과 항목(최소 1개~참가자 수, 부족분은 `X`로 채움), 진행 속도(빠르게/보통/느리게).
- 진행: 상단 참가자·하단 결과 항목 배치 → 서버가 사다리 구조·경로 생성 → 순차/동시 진행 → 전원 도착 시 `참가자 → 역할` 공개.
- 판정: 참가자:결과 1:1. 사다리 애니메이션은 서버 최종 매칭과 반드시 일치, 기기별 표시가 달라도 최종 결과는 동일.
- 결과 데이터: 참가자별 배정, 결과 항목, 진행 속도, 서버 시드.

## 4. Game 3 · 킹메이커
- 목적: 팀명 등 익명 제출 아이디어 중 하나를 투표로 확정.
- 설정: 1인당 투표 수, 결과 익명/실명, 주제 입력.
- 진행: 주제 제시 → **제출 2분**(120자 제한, 익명) → 텍스트만 공개 → 투표(자기 의견 투표 불가, **1분**) → 전원 투표 완료 시 마감 → 결과 공개.
- 확정: 최다 득표 즉시 확정. **동점이면 동점 후보만 결선 재투표**(기존 표 초기화, 후보 재제출 없음), 단독 1위 나올 때까지 반복.
- 판정: 익명 모드는 API·화면에 투표자 노출 금지(서버 내부에서만 구분). 허용치 초과 투표 불가. 제출 시간 초과=의견 없음, 투표 시간 초과=기권.
- 결과 데이터: 후보별 순위/득표수, 최종 후보+제시자, 동점 처리 결과.

## 5. Game 4 · 시간초 잡기
- 목적: 목표 시간에 가장 가깝게(또는 멀게) 멈춘 사람 선정.
- 설정: 주제, 목표 시간(5/7/10초), 기준(오차 최소/최대).
- 진행: 가이드 → 참가자별 로컬 START(요청 시각 기준 개별 타이머) → **2초까지만 숫자 표시, 이후 숨김** → STOP 1회 → 서버가 밀리초 단위 경과 기록 → 전원 완료/시간초과 시 마감 → 오차 계산 → 기준별 순위.
- 오차식: `절대 오차 = |정지 시간 - 목표 시간|`, 화면 표시는 부호 포함 시간차.
- 판정: 서버 경과 시간 기준(정수 ms), STOP 1회만 유효(재전송 무시). **START 안 하면 10초 후 자동 최하위**, 제한시간 = `목표 시간+3초`, 초과분 STOP은 불인정.
- 동점(ms까지 동일): 동점자끼리 재대결 1회.
- 결과 데이터: 목표 시간, 참가자별 정지 시간/시간차(표시용)/절대오차(판정용), 1위 오차, 순위, 최종 선정/탈락자.

## 6. Game 5 · 익명 저격
- 목적: 질문에 가장 어울리는 참가자를 익명 지목으로 선정.
- 질문 예시: PPT 장인 관상, 발표 잘할 사람, 지각할 사람, 든든한 팀장감 등.
- 설정: 질문(프리셋/직접입력 30자), 투표 시간(기본 10초), 중복 투표 가부.
- 진행: 질문+시간 공개 → 자신 제외 타겟 지목(제한시간 내) → 마감 후 피격 수 집계 → 최다 득표자 당첨.
- 동점: 동점자만 후보 유지, 방장이 재투표/대기방 복귀 선택(전원 미투표로 인한 동점도 동일 처리).
- 판정: 미선택=미투표, 자기 자신 지목 불가.
- 결과 데이터: 질문, 참가자별 피격 수, 최종 선정자.

## 7. Game 6 · 눈치게임
- 목적: 서로 눈치 보며 혼자 `UP`을 눌러야 생존.
- 설정: 동시 입력 판정 시간(기본 0.3초/하드 0.5초).
- 진행: 전원 UP 버튼 표시 → **15초 내** 1회 클릭 → 서버가 클릭 시각·순서 기록.
- 라운드 종료: 최초 동시 입력 발생 시 그 인원 탈락 후 종료, 없으면 마지막까지 남은 1명이 탈락. 라운드마다 탈락자 제거하고 반복, 1명 남을 때까지.
- 최종: 마지막 1명 남으면 그 인원도 탈락 처리(=최종 결과 도출). 전원 탈락 시 방장이 대기방 복귀/처음부터 다시 선택.
- 판정: 판정 시간 내 2인 이상 클릭=전원 동시 입력 탈락(순서 무관), 혼자 입력=통과. 라운드당 1회만 클릭 가능, 탈락자 추가입력 무시, 연결 끊기면 즉시 탈락. 시간 내 미입력자는 전원 탈락.
- 동시 입력 예시(0.3초 기준): 2.00초/2.12초 클릭한 둘은 동시 탈락(간격 0.12초), 2.62초 클릭자는 정상 통과(0.5초 이상 차이).
- 결과 데이터: 전체 클릭 순서, 참가자별 클릭 시각, 동시 입력 그룹, 라운드별 탈락자.
