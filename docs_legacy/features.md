## 1. 표기

**담당 레이어**

| 표기 | 뜻 |
|---|---|
| `FE` | 프론트엔드 (React + Vite · TypeScript) |
| `BE` | 백엔드 (Python · FastAPI) |
| `RT` | 실시간 (WebSocket 이벤트) |
| `LS` | 브라우저 로컬스토리지 |

**구현 상태**

| 표기 | 뜻 |
|---|---|
| ⬜ | 미착수 |
| 🔶 | 진행 중 |
| ✅ | 완료 |

`mvp/`는 화면·연출 검증용 프로토타입이므로 상태에 반영하지 않는다. 상태는 `frontend/`·`backend/` 기준이다.
