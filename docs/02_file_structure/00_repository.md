## 언제 채우나

**백엔드·프론트엔드 초기 스캐폴딩이 올라온 직후**에 작성한다.
디렉터리를 만들기 전에 미리 쓰면 실제 구조와 어긋나서 오히려 방해가 된다.

## 현재 저장소 구조

```
ModuPick/
├── README.md      저장소 진입점
├── docs/          스펙 정본
└── legacy/        폐기된 구 문서 (로컬 전용 · .gitignore 처리됨)
```

## 무엇을 쓸 것인가

작성할 때 아래를 담는다.

| 항목 | 설명 |
|---|---|
| 최상위 레이아웃 | 백엔드·프론트엔드·인프라 디렉터리를 어떻게 나눴는지 |
| 백엔드 패키지 구조 | FastAPI 라우터·서비스·모델·소켓 핸들러의 배치 규칙 |
| 프론트엔드 디렉터리 | React 컴포넌트·페이지·상태·API 클라이언트의 배치 규칙 |
| 파일 명명 규칙 | 컴포넌트·모듈·테스트 파일의 이름 규칙 |
| 어디에 무엇을 추가하나 | "새 게임을 추가하려면 어느 파일을 건드리나" 같은 실용 안내 |
