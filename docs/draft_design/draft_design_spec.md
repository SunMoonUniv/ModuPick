## 1. 표기 규칙

- **화면번호 체계:** `S-NN` = 주 화면 / `S-NNa` = 게임 가이드 팝업 노출 상태 / `S-NNb` = 결과 화면 / `S-NNc` = 예외 상태 / `C-NN` = 전 화면 공용 컴포넌트·모달
- **권한 표기:** `방장(Host)` = 방을 만든 사람, `참여자(Player)` = 코드로 입장한 사람
- **UI 요소 타입:** 텍스트 / 입력 / 버튼 / 리스트 / 카드 / 뱃지 / 모달 / 캔버스(애니메이션)
- 본 문서의 서버 이벤트명은 **설계 제안**이며, API 명세 확정 시 갱신 대상입니다.

### 2.2 신규 파일 전환 시 확인 사항

1. **`00 · 디자인 규격(Design Spec)` 프레임이 신규 파일에 없습니다.** 기존 ModuPick 파일의 `936:406`을 그대로 쓸지, 신규 파일에 규격 프레임을 새로 만들지 결정이 필요합니다.
2. **대기방 프레임명이 서로 바뀜어 있습니다.** Figma `542:422`는 이름이 `S-04P`이지만 내용은 **방장** 화면이고, `542:2783`은 이름이 `S-04H`이지만 내용은 **참여자** 화면입니다. 위 표는 본 문서의 규칙(S-04H=방장, S-04P=참여자)에 맞춰 매핑했으니, **Figma 프레임명 수정**을 권장합니다.
3. **`S-06` / `S-06a` 프레임(542:935, 542:3938)은 빈 상태**입니다. 해당 설계서는 기획안 기반 선행안이며 시안 확정 후 갱신 대상입니다.
4. `S-01a`는 신규 파일에서 `C-04 · 표지 + 이미 진행 중인 방 팝업 (X로 닫음)` 이라는 이름으로 존재합니다(542:5011).

```
S-01 표지 ─┬─ [새 방 만들기] ─→ S-02 방 만들기 ─→ S-03 프로필 설정 ─→ S-04H 대기방(방장)
           │
           └─ [코드 입력 + 참여] ─→ S-03 프로필 설정 ─→ S-04P 대기방(참여자)
                    └─ 진행 중인 방 → C-04 팝업 (S-01a)

S-04H/S-04P ─[방장: 게임 선택 + 설정 + 게임 시작]→ 게임 화면 (S-05 ~ S-10)
     ↑                                                    │
     │                                        C-01 게임 가이드 3초 자동 노출 (S-0Xa)
     │                                                    ↓
     └────[대기방으로]──── 결과 화면 (S-0Xb) ←── 결과 확정 후 3초
                              └─[다시 하기]→ 동일 설정으로 재시작 (가이드 미노출)

예외: 동점 → C-02 / 전원 탈락 → C-03
```

## 4. 전 화면 공통 규칙

### 4.1 권한

- 게임 종류·옵션·시작 여부는 **방장만** 설정할 수 있고, 참여자는 읽기 전용으로 확인만 가능하다.
- 방장이 게임을 시작하면 모든 참가자의 화면이 **동시에** 해당 게임으로 전환된다.
- 게임 시작 시점의 참가자 목록을 해당 회차의 참가자로 **고정**한다.
- 최소 2명 ~ 최대 10명. 정원 미만이어도 전원 `준비 완료`면 시작 가능.

### 4.2 방 생명주기

- 초대 코드(`MODU-XXXXXX`)는 방이 삭제될 때까지 유효하다.
- **방장이 퇴장하면 방은 삭제(폭파)된다.** 게임 중이었다면 전원 자동으로 S-01로 이동하고 `방장이 이탈하였습니다` 팝업을 노출한다.
- 방장은 참여자를 강제 퇴장시킬 수 있다.
- **게임이 진행 중인 방에는 신규 접속이 불가**하며 C-04 팝업을 노출한다.

### 4.3 실시간 동기화·판정

- 게임 상태와 결과는 모든 참가자 화면에서 동일하게 보여야 한다.
- 무작위 결과는 **서버에서 생성**하며 클라이언트가 임의로 재결정하지 않는다.
- 시간 기반 게임은 화면 애니메이션이 아닌 **서버 기준 시각**으로 판정한다.
- 동일 입력이 재전송되어도 **1회만** 처리한다(멱등).
- 이미 종료된 회차에 도착한 입력은 판정에 반영하지 않는다.
- 확정된 결과는 참가자의 퇴장·재접속으로 변경되지 않는다.

### 4.4 게임 시작·종료 시퀀스

1. 방장 게임 선택 → 2. 옵션 설정 → 3. 참가자 `준비 완료` 확인 → 4. 방장 `게임 시작`
2. 전원 화면에 **게임 가이드 3초** 표시 (C-01) → 6. 가이드 종료 후 서버 기준 게임 시작
3. 게임 화면 내 `?` 버튼으로 가이드 재호출 가능 (게임은 멈추지 않음)
4. 결과 확정 → 게임 화면에서 결과 연출 → **공개 시점부터 3초 후** 결과 화면으로 이동
5. 결과 화면에서 이미지 저장 가능 / 방장은 `다시 하기` 또는 `대기방으로 복귀` 선택
6. **동점 재대결·전원 탈락 재시작·다시 하기 시에는 가이드를 표시하지 않는다.**
