# Game 4 · 시간초 잡기 (`S-08`)

> 공통 규칙은 [`00_common.md`](00_common.md), 화면 규격은 [`07_design/03_screens.md`](../07_design/03_screens.md), 통신은 [`06_api/02_socket.md`](../06_api/02_socket.md)를 본다.
> 최종 수정: 2026-07-26

---

## 목적
방장이 정한 **목표 시간에 가장 가깝게(또는 가장 멀게)** 타이머를 멈춘 참가자를 뽑는다.

## 진행 순서
1. 전원 화면에 가이드 팝업(`M-01`)이 3초간 표시된다.
2. 가이드가 사라지면 **서버가 전원의 타이머를 동시에 출발**시킨다([D-24](../DECISIONS.md#d-24), 승인 대기).
   - **참가자가 누르는 START 버튼은 없다.** 참가자의 입력은 `STOP` 하나뿐이다.
3. 참가자 화면에 **경과 시간이 2.00초까지만 보이고, 그 뒤로는 숨겨진다**(`?.??` 마스킹).
4. 참가자는 원하는 순간에 `STOP`을 **한 번** 누른다.
5. 서버가 각 참가자의 경과 시간을 **정수 밀리초**로 기록한다.
6. 전원이 입력을 마치거나 제한 시간에 도달하면 라운드를 종료한다.
7. 서버가 목표 시간 대비 오차를 계산한다.
8. 방장이 고른 기준으로 순위를 정한다.
9. 결과 화면(`S-08R`)에 정지 시간·오차·순위·최종 선정자를 표시한다.

> ⚠️ [D-24](../DECISIONS.md#d-24)가 승인 대기다. 참가자 개별 START 방식이 채택되면 2번이 바뀐다.

## 오차 계산

```
절대 오차 = |참가자의 정지 시간 − 목표 시간|     ← 판정용
시간 차이 = 참가자의 정지 시간 − 목표 시간       ← 화면 표시용 (부호 포함)
```

목표 시간이 5.00초일 때 예시:

| 참가자 | 정지 시간 | 절대 오차(판정) | 화면 표시 |
|---|---|---|---|
| A | 4.91초 | 0.09초 | −0.09초 |
| B | 5.03초 | 0.03초 | +0.03초 |
| C | 5.42초 | 0.42초 | +0.42초 |

- `오차가 적은 사람` 기준 → **B** 선정
- `오차가 큰 사람` 기준 → **C** 선정

## 판정 규칙
- **화면 애니메이션 시간이 아니라 서버 수신 시각**으로 판정한다([D-14](../DECISIONS.md#d-14)).
- 시간은 부동소수점이 아닌 **정수 밀리초**로 기록한다.
- `STOP`은 **한 번만** 누를 수 있다. 재전송해도 최초 입력만 인정한다.
- **제한 시간 = 목표 시간 + 3초.**
- 제한 시간까지 누르지 않은 참가자는 **자동 최하위** 처리한다.
- 제한 시간이 지나 도착한 `STOP`은 인정하지 않는다.

## 동점 처리
밀리초 단위 오차까지 같으면 [`00_common.md` §3 동점 처리](00_common.md#3-동점--전원-탈락-공통-처리)를 따른다.
