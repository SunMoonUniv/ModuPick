# Game 6 · 눈치게임 (`S-10`)

> 공통 규칙은 [`00_common.md`](00_common.md), 화면 규격은 [`07_design/03_screens.md`](../07_design/03_screens.md), 통신은 [`06_api/02_socket.md`](../06_api/02_socket.md)를 본다.
> 최종 수정: 2026-07-26

---

## 목적
서로의 타이밍을 피해 `UP` 버튼을 눌러야 하는 심리전 게임. 겹치면 둘 다 탈락한다.

## 진행 순서
1. 전원 화면에 `UP` 버튼이 표시된다.
2. 게임이 시작되면 참가자들은 **제한 시간 15초 안에** 버튼을 한 번 누른다.
3. 서버가 각 참가자의 **클릭 시각과 순서**를 기록한다.
4. 두 명 이상이 **판정 시간 안에** 눌렀다면 **동시 입력**으로 판정한다.
5. 동시 입력한 참가자는 **전원 탈락**한다.
6. 동시 입력이 없었다면, **끝까지 누르지 않고 남은 참가자가 탈락**한다.
   (제한 시간까지 누르지 않은 참가자를 탈락 처리하는 것과 같은 규칙이다)
7. 전원이 동시 입력으로 탈락하면 [`00_common.md` §3 동점 처리](00_common.md#3-동점--전원-탈락-공통-처리)를 따른다.
8. 게임이 길어질수록 배경 점멸·텍스트 흔들림으로 압박감을 높인다.
9. 종료 후 클릭 순서·탈락자·최종 결과를 공개한다.

## 동시 입력 판정 예시

판정 시간이 0.3초일 때:

| 참가자 | 클릭 시각 | 판정 |
|---|---|---|
| A | 2.00초 | B와 동시 입력 |
| B | 2.12초 | A와 동시 입력 |
| C | 2.62초 | 정상 입력 |

A와 B의 간격은 0.12초이므로 **둘 다 탈락**한다.
C는 A·B와 0.3초 이상 차이가 나므로 정상 입력으로 인정한다.

## 종료 방식 (방장 설정 — [D-25](../DECISIONS.md#d-25))

**① 첫 탈락 발생 시 종료** (기본값)
- 최초로 동시 입력이 발생하면 해당 참가자들을 탈락자로 확정하고 게임을 끝낸다.
- 동시 입력 없이 모두 순서대로 눌렀다면, 끝까지 남은 참가자가 탈락한다.

**② 최후의 1명까지 반복**
- 각 라운드의 탈락자를 제외하고 다음 라운드를 진행한다.
- 서버는 라운드마다 클릭 여부와 순서를 초기화한다.
- 한 명이 남으면 그 참가자를 최종 결과로 발표한다.

## 판정 규칙
- 각 참가자는 **라운드마다 한 번만** 누를 수 있다.
- 판정 시간 안에 입력한 참가자는 **순서와 무관하게 전원 동시 입력** 처리한다.
- 동일한 클릭 요청이 재전송되어도 한 번만 인정한다.
- **탈락한 참가자의 추가 입력은 무시**한다.
- 게임 중 연결이 끊긴 참가자는 **즉시 탈락** 처리한다.
- **서버 수신 시각**을 최종 판정 기준으로 사용한다([D-14](../DECISIONS.md#d-14)).
