# Game 2 · 랜덤 사다리 (`S-06`)

> 공통 규칙은 [`00_common.md`](00_common.md), 화면 규격은 [`07_design/03_screens.md`](../07_design/03_screens.md), 통신은 [`06_api/02_socket.md`](../06_api/02_socket.md)를 본다.
> 최종 수정: 2026-07-26

## 목적
PPT·발표·자료조사 같은 **여러 역할을 한 번에** 배분한다.

## 시작 조건
- **결과 항목 개수 ≤ 참가자 수.** 항목이 참가자보다 많으면 시작할 수 없다(`INVALID_CONFIG`).

## 진행 순서
1. 화면 상단에 **참가자가 자동 배치**된다. 참가자가 자리를 고르지 않는다([D-23](../DECISIONS.md#d-23)).
2. 화면 하단에 방장이 입력한 역할·결과 항목이 배치된다.
3. **서버가 사다리 구조와 참가자별 경로를 미리 생성**한다([D-13](../DECISIONS.md#d-13)).
4. **방장이** 진행 방식을 고른다.
   - **순차 공개** — 캐릭터를 하나씩 클릭해 한 명씩 경로를 따라간다
   - **동시 시작** — `동시 시작!` 버튼으로 전원을 한 번에 진행한다
5. 캐릭터가 사다리를 따라 이동한다. 속도는 방장 설정(`빠르게`/`보통`/`느리게`)을 따른다.
6. 모든 경로가 끝나면 최종 연결을 공개한다.
7. 결과 화면(`S-06R`)에 `참가자 → 역할` 전체 배정을 표시한다.

> **참가자에게는 입력이 없다.** 사다리는 방장이 진행하고 나머지는 지켜본다.
> 구 `api.md`에 있던 `ladder.pick { laneIndex }`(참가자 레인 선택)는 폐기됐다([D-23](../DECISIONS.md#d-23)).

## 진행 속도

| 설정 | 동작 |
|---|---|
| 빠르게 | 경로 애니메이션을 짧게 표시하거나 결과로 빠르게 이동 |
| 보통 | 일반 속도로 경로 표시 |
| 느리게 | 각 이동을 길게 보여 긴장감을 높임 |

## 판정 규칙
- 기본 모드는 **참가자와 결과 항목을 1:1로 연결**한다.
- 결과 항목이 참가자 수보다 적으면 **남는 참가자 자리는 `X`로 표시**한다.
- **사다리 애니메이션은 서버가 생성한 최종 매칭과 반드시 일치**해야 한다.
- 화면 크기나 기기에 따라 경로가 다르게 보여도 **최종 배정 결과는 같아야 한다.**
