# Game 1 · 운명의 룰렛 (`S-05`)

> 공통 규칙은 [`00_common.md`](00_common.md), 화면 규격은 [`07_design/03_screens.md`](../07_design/03_screens.md), 통신은 [`06_api/02_socket.md`](../06_api/02_socket.md)를 본다.
> 최종 수정: 2026-07-26

---

## 목적
참가자 중 팀장·발표자·벌칙 수행자처럼 **한 명**을 무작위로 뽑는다.

## 진행 순서
1. 참가자 이름과 캐릭터가 룰렛 조각으로 배치된 화면이 뜬다.
2. **모든 조각은 동일한 당첨 확률**을 갖는다 (6명이면 각 16.7%).
3. 방장이 `PICK!`을 누른다.
4. **서버가 무작위 시드와 최종 당첨 결과를 먼저 생성한다**([D-13](../DECISIONS.md#d-13)).
5. 모든 참가자 화면에서 **동일한 룰렛 회전 애니메이션**이 재생된다.
6. 3~5초 후 룰렛이 멈추며 당첨자를 공개한다.
7. 결과 화면(`S-05R`)으로 이동한다.

## 판정 규칙
- **룰렛 애니메이션은 연출일 뿐이다.** 실제 당첨은 서버가 정한다.
- 추첨 도중 참가자가 나가도 **시작 시 고정된 후보 목록과 결과를 유지**한다.

## 결과 데이터
후보 목록 · 당첨자 · 결과 재현용 서버 시드
