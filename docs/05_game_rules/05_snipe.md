## 목적
특정 질문에 가장 어울리는 참가자를 **익명 지목**으로 고른다.

## 질문 예시
- 숨겨진 PPT 장인 관상은?
- 발표를 가장 잘할 것 같은 사람은?
- 가장 먼저 지각할 것 같은 사람은?
- 팀장을 맡기면 가장 든든할 것 같은 사람은?

## 진행 순서
1. 질문과 투표 시간(기본 10초)이 공개된다.
2. 참가자는 제한 시간 안에 **자신을 제외한** 참가자 한 명을 지목한다.
3. 투표 마감 후 참가자별 피격 수를 집계한다.
4. **최다 피격자가 당첨자**가 된다.
5. 동점이면 [`00_common.md` §3 동점 처리](00_common.md#3-동점--전원-탈락-공통-처리)를 따른다.
6. 결과 화면(`S-09R`)에 질문·득표 수·최종 당첨자를 표시한다.

## 판정 규칙
- **자기 자신을 지목할 수 없다.** 본인은 지목 대상 목록과 사격장 그리드 **양쪽 모두에서 제외**된다.
- 지목하지 않은 참가자는 **미투표**로 처리한다.
- 누가 누구를 지목했는지는 **결과에서도 공개하지 않는다.**

## 결과 데이터
질문 · 참가자별 피격 수 · 최종 선정자
