# 화면 ID 정본 (Screen Map)

> 이 문서는 **화면을 가리키는 유일한 이름**을 정의한다.
> 다른 모든 문서(기획·게임규칙·API·디자인)는 여기 정의된 ID만 사용한다.
> 최종 수정: 2026-07-26 · 소유자: 전원 합의 문서(변경 시 [TEAM.md](../TEAM.md) 참조)

---

## 1. 왜 이 문서가 필요한가

정리 이전에는 같은 화면을 가리키는 이름이 **4가지 체계로 흩어져** 있었다.

| 체계 | 쓰인 곳 | 예 |
|---|---|---|
| `S-0x` / `C-0x` | 구 `api.md` | `S-04P`, `C-01` |
| `§7.x` 절 번호 | 구 `design.md` | `§7.4 대기방` |
| Figma 노드 ID | 구 `design.md` | `975:7`, `539:2969` |
| 한글 화면명 | 구 `document.md` | "실시간 대기방 화면(방장 시점)" |

매핑표가 없어 문서 간 상호 참조가 불가능했고, 실제로 **같은 ID가 정반대 뜻으로 쓰인 사례**도 있었다.
구 `api.md`는 한 파일 안에서 `S-04P`를 "방장"으로도 "참여자"로도 썼다(구 `api.md:283` ↔ `:393`, `:404`).

그래서 정본 ID에는 **역할을 접미어로 명시**한다. `S-04P` 같은 축약은 금지한다.

## 2. 명명 규칙

```
S-{번호}[-{HOST|GUEST}][-{서브}]     화면(Screen)
M-{번호}                              모달·팝업(Modal)
```

- **번호**: 사용자 여정 순서를 따른다. 게임은 `S-05`~`S-10`으로 6종 고정.
- **`-HOST` / `-GUEST`**: 같은 화면이 역할에 따라 다르게 보일 때만 붙인다. 구분이 없으면 생략.
- **`R` 접미**: 해당 게임의 **결과 화면**(Result). 예: `S-05` 진행 → `S-05R` 결과.
- **`-1`, `-2` 접미**: 한 게임 안에서 순차 진행되는 단계 화면. 예: 킹메이커 `S-07-1`(제출) → `S-07`(투표).
- **모달은 화면이 아니다.** 뒤 화면 위에 겹쳐 뜨는 것은 전부 `M-xx`.

**상태(phase)는 ID를 새로 만들지 않는다.** 한 화면 안에서 시간에 따라 바뀌는 것은 상태로 표기한다.
예: 시간초 잡기의 대기/진행/비공개는 전부 `S-08`이고, `S-08 (비공개 상태)`처럼 쓴다.

## 5. 화면 전이도

```
                         ┌──────────────────────────────┐
                         │  S-01  표지(메인 랜딩)        │
                         └───┬──────────────────┬───────┘
             [새 방 만들기]  │                  │  [코드 입력 · 참여]
                             ▼                  ▼
                  ┌──────────────────┐   (코드 검증)
                  │ S-02 방 만들기    │    ├─ 진행 중 방 → M-04 차단
                  └────────┬─────────┘    ├─ 정원 초과 → S-01 유지 + 에러
                           │              └─ 정상 ─────┐
                           ▼                           ▼
                  ┌────────────────────────────────────────┐
                  │  S-03  프로필 설정 (방장·참여자 공통)   │
                  └────────┬───────────────────┬───────────┘
                    방장 ▼                     ▼ 참여자
       ┌────────────────────────┐  ┌────────────────────────┐
       │ S-04-HOST  대기방(방장) │◀▶│ S-04-GUEST 대기방(참여) │
       └────────┬───────────────┘  └────────────────────────┘
                │ [게임 시작] — 전원 READY 필수(D-12)
                ▼
       ┌─────────────────────────────────────────────┐
       │  M-01  게임 가이드 팝업 · 3초 자동 (D-10)    │
       └────────┬────────────────────────────────────┘
                ▼
       ┌─────────────────────────────────────────────┐
       │  S-05 · S-06 · S-07-1→S-07 · S-08 · S-09 · S-10 │
       └────────┬────────────────────────────────────┘
                │           ├─ 동점 → M-02
                │           └─ 전원 탈락(눈치) → M-03
                ▼ (결과 확정 3초 후 자동 이동)
       ┌─────────────────────────────────────────────┐
       │  S-05R ~ S-10R  결과 발표                    │
       └────────┬────────────────────────────────────┘
         방장만 │ [↻ 다시 하기] → 같은 설정으로 재시작
                │ [← 대기방으로] → S-04-HOST / S-04-GUEST
                ▼
```

| 모달 | 트리거 | 발생 화면 |
|---|---|---|
| `M-01` | 게임 시작 직후(자동) / 게임 중 `?` 클릭 | `S-05`~`S-10` |
| `M-02` | 최다 득표·최소 오차 동점 | `S-07`, `S-08`, `S-09` |
| `M-03` | 전원 동시 입력 탈락 | `S-10` |
| `M-04` | `PLAYING` 상태인 방 코드로 입장 시도 | `S-01` |
| `M-05` | 참가자 카드 `✕` 클릭(방장) | `S-04-HOST` |
| `M-06` | 방장 `나가기` 클릭 | `S-04-HOST` |
| `M-07` | 참여자 `← 나가기` 클릭 | `S-04-GUEST` |
