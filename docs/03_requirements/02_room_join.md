# REQ-ROOM — 방 만들기·입장

> **대상**: 방 만들기·입장(ROOM) 도메인 요구사항 21항(REQ-ROOM-01~21)
> **작성일**: 2026-08-02
> **원천**: docs_legacy/requirements.md §4.1 US-101~105 · §3.4 방 생성 설정 · [../02_features/01_room_join.md](../02_features/01_room_join.md)(F-ROOM-01~17) · [../01_overview/06_design_decisions.md](../01_overview/06_design_decisions.md) D-01~D-04·D-16·D-17·D-46 · [01_global_rules.md](./01_global_rules.md)

표지에서 대기방 명단에 오르기까지의 요구사항이다. 로그인·회원가입이 없으므로 검증 부담이 전부 **초대 코드와 프로필 확정**에 몰린다. 입장은 슬롯 선점(대기 상태)과 프로필 확정(활성 상태) 두 단계이며, **정원 판정은 대기 상태 인원까지 세어** 프로필을 입력하는 중인 사람도 자리를 차지하게 한다. 이 절을 나누지 않으면 프로필 입력이 겹칠 때 정원을 넘겨 활성화된다.

## 입장 2단계와 정원 판정

정원을 정확히 지키려면 코드가 맞다와 명단에 올랐다 사이에 자리를 잡아 두는 단계가 필요하다.

| 단계 | 상태 | 근거 요구사항 | 다른 사람에게 보이나 | 정원에 세나 |
|------|------|---------------|:--------------------:|:-----------:|
| 코드 검증 | 없음 | REQ-ROOM-06 | 아니오 | 아니오 |
| 슬롯 선점 | 대기 | REQ-ROOM-10 | 아니오 | **예** |
| 프로필 확정 | 활성 | REQ-ROOM-16 | 예 | 예 |

방치된 대기 슬롯은 REQ-ROOM-18이 회수한다. 회수가 없으면 들어오다 만 사람이 자리를 영구히 점유해 정원이 조용히 줄어든다.
