# 도메인 용어

> **대상**: ModuPick 전 문서·구현이 공유하는 도메인 용어의 단일 정의
> **작성일**: 2026-08-02
> **원천**: docs_legacy/requirements.md §2 용어 · §3 게임 공통 기준 · [../README.md](../README.md)(전역 불변식) · [../01_overview/06_design_decisions.md](../01_overview/06_design_decisions.md)(제품 결정)

같은 것을 문서마다 다른 말로 부르면 규칙이 어긋난다. 본 문서가 용어의 정본이며 다른 문서는 여기서 정한 말을 그대로 쓴다. 특히 **탈락 · 안전 · 잔류**처럼 뜻이 뒤집히기 쉬운 말은 정의를 어기지 않는다 — 구 스펙에서 '탈락'을 두 가지 뜻으로 쓴 탓에 눈치게임 규칙이 성립하지 않았던 전례가 있다.

## 방과 사람

| 용어 | 정의 |
|------|------|
| **방(Room)** | 참가자가 모이는 단위. 방 제목·정원과 초대 코드를 가진다. 대기·진행·결과 중 한 상태에 있으며 삭제되면 코드가 무효가 된다 |
| **초대 코드** | 방을 가리키는 숫자 6자리. 표시할 때만 MODU- 접두어를 붙인다. 저장값에는 접두어가 없다 |
| **방장(Host)** | 방을 만든 사람. 게임 선택·설정·시작·강퇴·다시 하기·교착 해소 선택 권한을 가진다. 권한은 **다른 사람에게 넘어가지 않으며** 방장이 나가면 방이 삭제된다 |
| **참가자(Member)** | 방에 들어온 사람. **방장도 참가자에 포함된다.** 방장이 아닌 참가자를 가리켜야 할 때는 "방장을 제외한 참가자"로 쓴다 |
| **소개 태그** | 닉네임 옆에 붙는 한 줄 소개. 선택 입력이며 대기방 참가자 목록에 보인다 |
| **준비 완료** | 방장을 제외한 참가자가 게임 시작에 동의한 상태. **방장은 준비 상태를 갖지 않는다** |

## 판과 진행

| 용어 | 정의 |
|------|------|
| **라운드(Round)** | 게임 한 판. 방에 최대 하나만 존재하며 진행 상태일 때만 있다. 다시 하기는 새 라운드를 만들고, 결선·재대결은 같은 라운드 안의 단계 전환이다 |
| **단계(phase)** | 라운드 안의 진행 구간. 게임마다 다르며 전이 규칙은 각 게임 문서가 정한다 |
| **명단 스냅샷** | 게임 시작 순간의 참가자 목록. 게임이 끝날 때까지 바뀌지 않는다. 도중 이탈자도 이 목록에 남아 후보가 된다 |
| **유효 인원** | 명단 스냅샷 중 아직 연결이 살아 있는 인원. 판정 대상은 스냅샷이지 유효 인원이 아니다 |
| **주제(Topic)** | 이 게임으로 무엇을 정하는지 나타내는 문구. 템플릿 칩 또는 방장의 직접 입력으로 정한다 |
| **시드** | 라운드마다 서버가 뽑는 64비트 난수 씨앗. 같은 시드와 같은 입력이면 같은 결과가 나온다. 결과와 함께 저장되고 방이 사라질 때 삭제된다 |

## 시간과 판정

| 용어 | 정의 |
|------|------|
| **서버 도착 시각** | 참가자 입력이 서버에 닿은 시각. 서버 프로세스의 단조 시계 기준 정수 밀리초다. **시간·순서 판정의 기준**이며 클라이언트가 보낸 시각은 판정에 쓰지 않는다 |
| **판정창** | 두 입력을 "동시"로 볼지 가르는 시간 폭. 눈치게임에서만 쓰며 0.3초·0.5초 중 방장이 고른다 |
| **동시 입력 그룹** | 판정창 안에 들어온 입력의 묶음. 그룹을 나누는 규칙은 [../05_game_rules/07_nunchi.md](../05_game_rules/07_nunchi.md)의 의사코드가 정본이다 |
| **경과 시간** | 시간초 잡기에서 START부터 STOP까지 걸린 시간. **이 값만 클라이언트 단조 시계가 재고 서버가 범위를 검증한다** — 서버 도착 시각 원칙의 유일한 예외다 |
| **절대 오차** | 시간초 잡기의 판정값. 경과 시간과 목표 시간의 차이에서 부호를 뗀 값이다 |
| **시간 차이** | 시간초 잡기의 표시값. 부호를 포함해 목표보다 빨랐는지 늦었는지를 보인다. 판정에는 쓰지 않는다 |

## 결과와 상태

| 용어 | 정의 |
|------|------|
| **안전 확정** | 눈치게임에서 혼자 눌러 후보에서 **빠진** 상태. 다시 판정받지 않으며 이후 입력은 무시된다. **안전 확정은 좋은 상태다** |
| **잔류** | 눈치게임에서 후보로 **남은** 상태. 판정창 안에 겹쳐 누른 사람과 누르지 않은 사람이 잔류한다. 마지막까지 잔류한 한 명이 뽑힌다 |
| **뽑힌다 · 선정** | 게임의 결과로 지목되는 것. 그것이 상인지 벌인지는 주제가 정하므로 문서는 **당첨·탈락 같은 가치어를 쓰지 않는다** |
| **기권** | 제한 시간 안에 투표하지 않은 상태. 어떤 후보의 표도 늘리지 않는다 |
| **미입력** | 제한 시간 안에 어떤 입력도 하지 않은 상태. 게임별 기본값으로 자동 처리한다 |
| **유효표** | 실제로 후보에게 던져진 표. 기권은 유효표가 아니다 |

**'탈락'이라는 말을 쓰지 않는다.** 눈치게임에서 후보에서 빠지는 것이 유리하고 남는 것이 불리한데, '탈락'은 두 뜻으로 다 읽힌다. 빠지는 쪽은 **안전 확정**, 남는 쪽은 **잔류**로만 쓴다.

## 반복과 교착

| 용어 | 정의 |
|------|------|
| **결선** | 최다 득표가 동점일 때 동점 후보만 남겨 다시 투표하는 것. 킹메이커·익명 저격에서 쓴다 |
| **재대결** | 절대 오차가 밀리초까지 같을 때 동점자끼리 다시 겨루는 것. 시간초 잡기에서 쓴다 |
| **반복 상한** | 결선·재대결의 최대 횟수. **3회**이며 초과하면 자동 진행을 멈춘다 |
| **교착 해소** | 반복 상한을 소진하고도 단독 승자가 없을 때 방장이 다시 시작·대기방으로 중에서 고르는 절차 |
| **무효 라운드** | 눈치게임에서 생존자 전원이 같은 판정창에 눌러 아무도 안전 확정하지 못한 라운드. 교착 해소와 같은 방식으로 방장이 처리한다 |

## 연결과 수명

| 용어 | 정의 |
|------|------|
| **이탈** | 참가자가 방을 떠난 것으로 서버가 확정한 상태. 소켓이 끊긴 즉시가 아니라 **유예를 지난 뒤** 확정한다 |
| **이탈 유예** | 소켓이 끊긴 뒤 이탈로 확정하기까지 기다리는 시간. 모바일에서 앱을 잠깐 전환하는 것과 실제 이탈을 가르기 위한 장치다. 값의 정본은 [../04_architecture/02_realtime_websocket.md](../04_architecture/02_realtime_websocket.md) |
| **재접속 불가** | 나갔던 사람이 같은 자격으로 돌아올 수 없다는 규칙. 다시 들어오면 새 참가자이며 진행 중인 판에는 낄 수 없다. **이탈 유예는 재접속을 허용하는 장치가 아니라 이탈 확정을 늦추는 장치다** |
| **방 폐기** | 방과 그 하위 데이터를 삭제하는 것. 방장 이탈·마지막 참가자 이탈·10분 무활동에서 일어난다 |

## 쓰지 않는 말

| 쓰지 않는 말 | 대신 쓰는 말 | 이유 |
|-------------|-------------|------|
| 탈락 | 안전 확정 · 잔류 | 뜻이 뒤집혀 읽힌다 |
| 당첨 · 벌칙 | 뽑힌다 · 선정 | 결과의 의미는 주제가 정한다 |
| 유저 · 플레이어 | 참가자 | 용어를 하나로 유지한다 |
| 호스트 | 방장 | 한국어 용어를 정본으로 한다 |
| 재접속 · 복구 | (쓰지 않음) | 제품에 그 기능이 없다. 부정형으로만 언급한다 |
| 관전 | (쓰지 않음) | 제품에 그 기능이 없다 |
