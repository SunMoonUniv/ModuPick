# 디자인 규칙 (Design Rules)

> 화면 제작·구현의 **단일 기준**이다. 시각 토큰(색·타입·그리드)뿐 아니라 **콘텐츠·데이터 규칙**과 **화면별 규격**까지 정의해, "초대코드 자릿수" 같은 실수를 원천 차단한다.
> 화면 ID는 [`04_requirements/01_screen_map.md`](../04_requirements/01_screen_map.md), 게임 규칙은 [`05_game_rules/00_common.md`](../05_game_rules/00_common.md)를 따른다.
> 최종 수정: 2026-07-26 · 소유자: [TEAM.md](../TEAM.md) 참조

## 1. 기본 전제

**Figma 정본 파일**: `xXFnM0pydDOcK12CS10X9l` ([D-31](../DECISIONS.md#d-31))

| 페이지 | 노드 | 역할 |
|---|---|---|
| **디자인 규격** | `1033:7` | 개발 전달용 규격 시트 14장(00 파운데이션 + 01~13 화면별). **치수·컴포넌트·상태·인터랙션의 단일 출처** |
| **정본 화면** | `948:7` | 완성 시안 6종. **시각 기준이자 규격 시트 METRICS의 실측 근거** |
| **초안** | `539:17` | 나머지 전 화면·상태·모달. ⚠️ **깨진 부분이 많다** |

**초안(`539:17`)의 치수·수치는 신뢰하지 않는다.** 폰트 극소·정렬 이탈·데이터 불일치가 다수다.
초안에서는 "어떤 패널·콘텐츠·상태가 있는가"만 취하고, 실제 제작은 이 문서의 확정 규격으로 한다.
초안의 대표 결함은 각 화면 항목의 **`초안 교정`** 줄에 명시했다.

> **반응형은 범위 밖이다.** FHD **1920×1080 고정**만 정의한다. 모바일·노트북 대응은 [`01_overview/00_product.md` §6](../01_overview/00_product.md#6-개발-범위)에서 범위 밖으로 확정됐다.

## 2. 폰트 체계 (3폰트 고정)

| 역할 | 폰트 | 쓰는 곳 |
|---|---|---|
| 히어로 · 화면 제목 | **Black Han Sans** | 화면 제목(44), 결과 당첨자(60+), WINNER/PICK 등 대형 강조 |
| 이름 · 게임제목 · 버튼 | **Do Hyeon** | 참가자/멤버 이름, 게임 카드 제목, 버튼·밴드 타이틀 |
| 본문 · 서브라인 · 채팅 | **IBM Plex Sans KR (Medium)** | 서브라인, 설명, 채팅 말풍선, 캡션, 칩, 타임스탬프 |

- **나눔고딕 계열(NanumGothic / NanumGothicCoding) 사용 금지.** Gothic A1 · 42dot도 채택하지 않는다.
- 개성체(Yeon Sung 등)는 본문 금지 — 필요 시 연출 배너 강조에만.

| px | 폰트 | 용도 |
|---|---|---|
| 18 | IBM | 메타 · 뱃지 · 타임스탬프 (**하한**) |
| 20 | IBM | 서브라인 · 설명 |
| 22 | IBM | 기본 본문 · 채팅 말풍선 |
| 24 | Do Hyeon | 버튼 · 칩 · 강조 |
| 28 | Do Hyeon | 이름 · 카드 제목 |
| 34 | Do Hyeon | 게임 헤드라인 |
| 40 | Black Han | 헤드 · 화면 제목(축소형) |
| 44 | Black Han | 화면 제목 |
| 60 / 88 | Black Han | 결과 당첨자 / 히어로 수치 |

## 5. 그리드 & 셸

```
프레임              1920 × 1080  (FHD 고정 · 반응형 미적용)
셸(테두리)          21,17  1877×1046  · stroke 잉크 5 · radius 20
코너 마커 4개        29,23 / 1874,23 / 29,1040 / 1874,1040 · 17×17 핑크
콘텐츠 좌우 여백     59  → 콘텐츠 폭 1803 (x 59~1862)

content 컨테이너     59,40  1803×1000 · 세로 오토레이아웃 · gap 26
 ├ header          1803×93   (y40~133)   · 제목 Black Han 44 + 서브 IBM 20
 ├ body            1803×747  (y159~906)  · FILL
 └ status-band     1803×108  (y932~1040) · fill 잉크

검산: 40 + 93 + 26 + 747 + 26 + 108 = 1040 ✓  (셸 하단 1063 − 여백 23)

2컬럼 표준          좌 1221 + 갭 32 + 우 550        = 1803 ✓
3컬럼 (대기방)       549 + 28 + 528 + 28 + 670       = 1803 ✓
```

> ⚠️ **`y144~914` / `y938`은 폐기된 값이다**([D-30](../DECISIONS.md#d-30)).
> 그 값은 초안 보정 계획값이라 정본 실측과 6px 어긋난다. **위 `y159~906` / `y932`가 정답**이며,
> 규격 시트 `1033:7` 전 장이 이 값을 따른다. 구 `design.md`는 폐기 선언을 해놓고도 세 곳에서 옛 값을 그대로 강제하고 있었다.

| `S-03` 프로필 | 하단 밴드 없음 → `header 1803×151 + body 1803×823` (입장 CTA가 좌측 카드 안에 있다) |
