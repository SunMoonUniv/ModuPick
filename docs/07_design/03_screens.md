### `S-04-HOST` / `S-04-GUEST` 대기방 · 확정 `975:7`(방장) · 초안 `539:2969`(참여자)

  **세 컬럼 상단선 `y=159` 통일**([D-30](../DECISIONS.md#d-30)).
- **참가자 카드**: 아바타 60 + 이름 28 + 서브라인 20(`@handle · 역할`) + 상태 뱃지(`방장`=옐로 / `✓ READY`=그린 / `· 준비 중`=회색) + **강퇴 `✕`(방장 시점만)**. 하단 점선 빈자리 행 `? 빈 자리 N · 초대 링크로 참여 대기`
- **채팅**: `◆ CHAT · 대기방 채팅 · 실시간`. 오토레이아웃 메시지 —
  상대 = 아바타 + 이름 + **흰 말풍선** + 시간 / 본인 = **우측 정렬 핑크 말풍선** / 시스템 = **중앙 라벤더 칩**(`유진님이 입장했어요`, `🎮 방장이 '운명의 룰렛'을 골랐어요`) / 입력 중 = `●●● 도윤님이 입력 중…`.
  하단 입력창 `메시지 입력…` + `▶` 전송(시안)
- **게임 선택**: 6종 2×3 카드(아이콘 + 제목 Do Hyeon + 한줄부제, 선택 = 핑크 배경 + `✓`) + 아래 **선택 게임 설정 패널**(`⚙ ○○ 설정` + `게임을 바꾸면 설정도 자동으로 바뀌어요` + `무엇을 정할까?` 칩[팀장/발표자/직접 입력] + 입력 `예) 오늘 청소 당번은?` 0/16)
- **상태 밴드**: `🎮 ○○ 준비 완료!` + `2명 이상이면 시작할 수 있어요 · 현재 N명 · READY K/M` + `[🎲 랜덤 게임]`(시안) `[▶ 게임 시작]`(핑크)
- **방장 vs 참여자 차이**
  - 참여자 우측 패널 = **열람 전용** — `방장이 고르는 중 · 참여자는 선택할 수 없어요` + 우 배지 `방장만 변경 가능`, 설정 패널은 `🔒 ○○ 설정 · 읽기 전용`(입력 `읽기 전용` 라벨)
  - 참여자 하단 밴드 = `⏳ 방장이 시작하기를 기다리는 중` + `[← 나가기]`(시안) `[✓ 준비 완료]`(잉크). 준비 완료를 누르면 방장 화면에 READY가 반영된다
  - 게임 · 설정 · 시작 · 강퇴 · 랜덤 게임은 **방장만**([`02_content_rules.md`](02_content_rules.md)). 방장은 항시 준비 상태
- `초안 교정`: 참여자본 방코드 `427132`(6자리) → **`MODU-####` 4자리**. 도윤 행 정체불명 시안 `4` 배지 제거. 채팅 타임스탬프·설정 라벨 극소 → 하한 준수.

## 결과 화면 4변형 (공통 셸 + 본문 교체)

공통 셸 = **헤더(`결과 발표 · RESULT` + 게임·목적·방코드 서브라인, 컨페티) + 좌 결과 카드(1221) + 우 액션 패널(550) + (선택) 하단 밴드(1803)**. 본문만 게임별로 교체한다.

| 변형 | 게임 | 좌 결과 카드 | 하단 밴드 |
|---|---|---|---|
| **승자형** | `S-05R` · `S-08R` · `S-09R` | WINNER 히어로(헤일로+왕관+아바타+이름 중앙) + `[게임·목적 당첨]` pill + **Stat 3색 타일**(시안·핑크·옐로) | **Safe Band**(비껴간/기록 분포 칩, **멤버색 파스텔**) |
| **배정형** | `S-06R` | `역할 배분 결과` + 참가자→역할 2×3 카드 + 통계칩 3 + 잠금 노트 | 없음 |
| **개표형** | `S-07R` | 확정 팀명 + Stat 3 + 개표 리스트(익명/실명 토글) | 없음 |
| **기록형** | `S-10R` | 요약 + 범례 + Stat 4 + 라운드별 판정 테이블(3색) | 없음(통과 = 민트 칩) |

**우 액션 패널 (전 변형 공통)**

- `[⧉ 결과 이미지 저장]`(잉크, 상단) + `⧉ 결과를 PNG 이미지로 내려받기` 안내
- 구분선 + `다음은? · 방장만 조작` + `[↻ 다시 하기]`(옐로) + `[← 대기방으로]`(흰)
- **버튼 세로 FILL로 균등 분배** · **xlsx 버튼 없음** · **저장은 PNG만, 전 게임 필수**
- 결과 도출 후 **3초 뒤 자동 이동**, 참여자는 방장 조작까지 결과 화면에서 대기(다시 하기/대기방 버튼은 방장만)
