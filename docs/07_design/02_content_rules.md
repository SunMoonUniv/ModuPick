## 방 · 코드

- **초대코드**: `MODU-####` — **`MODU-` + 숫자 정확히 4자리**. 자동 생성. 참여자는 뒤 4자리만 입력([D-01](../DECISIONS.md#d-01)).
  - ❌ `MODU-42713`(5자리) · `MODU-427132`(6자리) 금지 · ✅ `MODU-4271`
  - 미입력 표기는 `MODU- _ _ _ _`, 안내 문구는 `MODU-**** 자동 발급`
- **방 정원**: 최소 2 ~ 최대 10명. 인원 표기는 `현재 N명 / 최대 M명`.
  **인원은 방 생성 시 확정** — 대기방에서 변경하는 UI를 두지 않는다([D-32](../DECISIONS.md#d-32)).
- **방 이름**: 최대 30자. 생성 화면에 카운터(`12 / 30`). **프리셋 칩 없음**([D-33](../DECISIONS.md#d-33)) — 직접 입력만.
- **최대 인원 컨트롤**: 스테퍼 `[−][N 명][＋]` + "빠른 선택" 칩(2/4/6/8/10) + 슬라이더를 **한 값으로 동기화**해 제공.

## 프로필

- **닉네임**: **1~8자 · 필수 · 중복 불가.** 카운터 `5/8` 표시.
- **한 줄 소개**: 0~24자 · **선택** (`@handle · 역할` 형태)
- **아바타**: 동물 캐릭터 **15종을 5×3 그리드 한 화면에**. **페이징 없음**([D-08](../DECISIONS.md#d-08)).
  - 이미 선점된 아바타는 **회색 · 점선 · 잠금 라벨(`서연 선택`)로 비활성**(클릭 불가)
  - **`🎲 랜덤 뽑기` 없음**([D-09](../DECISIONS.md#d-09))
- 미리보기 대시보드로 "팀원에게 보일 내 모습"을 실시간 표시한다.
- **더미 참가자 6인**: 지호 · 서연 · 민준 · 하늘 · 도윤 · 유진. **실존 인물(교수님) 이름 금지.**

## 역할 · 권한

- **역할**: 방장(host) / 참여자(participant)
- **게임 선택 · 설정 · 시작 · 강퇴 · 랜덤 게임 · 다시 하기 · 대기방 복귀는 방장만.**
- **목적 설정**(팀장/역할/팀명/주제 정하기)은 **대기방 우측 패널 안에서** 끝낸다. 별도 화면으로 분리 금지.

## 없는 기능 (문구·UI 금지)

| 금지 | 이유 |
|---|---|
| "동시 관전 N명" 류 문구 | 관전(observer) 기능 없음 |
| 이모지 칩 · 플로팅 말풍선 | 빠른 리액션 없음. **단, 게임 상황 연출 배너는 유지** |
| xlsx 저장 버튼 | **결과 저장은 PNG만**. xlsx는 고도화 항목 |
| 대기방 인원 변경 컨트롤 | [D-32](../DECISIONS.md#d-32) |
| "인원은 대기방에서도 변경 가능" 안내 문구 | 위와 동일 |

## 게임

- **6종**: 운명의 룰렛 · 랜덤 사다리 · 킹메이커 · 시간초 잡기 · 익명 저격 · 눈치게임
- **게임 식별 색(6종 고유 틴트)**: 룰렛=핑크/퍼플 · 사다리=시안 · 킹메이커=옐로 · 저격=코랄 · 시간초=오렌지 · 눈치=퍼플
  → **표지 게임 카드 · 게임 아이콘 · 헤더 강조에만** 쓴다(오렌지·코랄은 이 용도 한정 확장 틴트).
  **화면 내부 상태색은 [`00_foundation.md` §4](00_foundation.md#4-팔레트-9색)의 9색 팔레트**를 따른다.
- **게임 가이드 팝업**: 시작 시 **자동 3초 노출(카운트다운)**, 이후 게임 화면 좌상단 `?`로 재열람.
  자동 노출본은 `✕` 비활성 · 재열람본은 `✕` 활성([D-10](../DECISIONS.md#d-10), 승인 대기). 상세는 [`03_screens.md`](03_screens.md) `M-01`.
- **게임별 방장 설정** — 근거는 [`05_game_rules/00_common.md` §2](../05_game_rules/00_common.md#2-게임별-방장-설정-요약)

  | 게임 | 설정 |
  |---|---|
  | 룰렛 | 결과 항목 |
  | 사다리 | 결과 항목(≤인원) + 진행속도(빠르게·보통·느리게) |
  | 킹메이커 | 익명\|실명 · 후보 **최대 120자** ([D-20](../DECISIONS.md#d-20)) |
  | 시간초 | 목표 **5·7·10초** · 선정 기준(오차 적은\|큰 사람) |
  | 저격 | 질문(프리셋\|직접) · 투표 시간(기본 **10초**) |
  | 눈치 | 동시 판정 **0.3초\|하드 0.5초** · **종료 방식(첫 탈락\|최후 1명)** ([D-25](../DECISIONS.md#d-25)) |

  ⚠️ **킹메이커의 `1인당 투표 수` 설정은 없다** — 1인 1표 고정([D-19](../DECISIONS.md#d-19), 승인 대기).

## 10. 카피 · 연출 톤

- **유쾌하되 공정.** "결과는 아무도 못 바꿔요 · 모두 똑같이" 류 공정성 문구를 결과·진행에 유지한다.
- **연출 배너**(누가 걸릴까?! 👀 / 역전각?! 🔥 등)는 유지 대상 — **리액션 기능과 다르다**(위 "없는 기능").
- **숫자·코드는 정보로 또렷하게** 보이게 한다(개성체 금지, IBM Plex Sans KR).
- 이모지는 강조 포인트로만 절제해 쓰고, 본문 가독성을 해치지 않게 한다.
