# SETUP — 게임 선택·설정

> **대상**: 게임 선택·설정(SETUP) 기능 명세
> **작성일**: 2026-08-02
> **원천**: docs_legacy/requirements.md §3.3 주제 템플릿 · §3.4 방장 설정 항목 · §4.3 US-301~307 · §6 D-16·D-17·D-18·D-19·D-20 · docs_legacy/features.md §4(구 F-301~F-313) · git 529e312 docs/api.md(game:select·game:config·game:random·game:start) · frontend/src/screens/Lobby.tsx

방장이 게임 6종 중 하나를 고르고 주제와 세부 설정을 정한 뒤 판을 시작하기까지의 표면이다. **선택과 설정은 방장만 하고 결과는 전원에게 즉시 반영된다** — 참가자 화면은 같은 값을 읽기 전용으로 받는다. 이 도메인은 게임 규칙 자체를 담지 않는다. 어떤 설정 항목이 존재하고 누가 바꾸며 언제 초기화되는지만 정하고, 그 값이 판정에 어떻게 쓰이는지는 [../05_game_rules](../05_game_rules/README.md)와 게임별 기능([05_games.md](./05_games.md))이 맡는다.

| **F-SETUP-13** | 규칙 안내 데이터 | 게임 6종의 한 줄 요약·진행 단계·판정 기준 문안을 제공한다. 방장뿐 아니라 전원이 열어볼 수 있다 | FE·BE | P1 | 🔶 |

## 설정 항목의 소유

설정 항목이 어느 문서에 적히는지 헷갈리지 않도록 축을 나눈다.

| 축 | 소유 | 내용 |
|----|------|------|
| 설정 표면의 존재와 동기화 | 본 문서 | 패널이 있고 방장만 바꾸며 전원에게 반영되고 게임을 바꾸면 초기화된다는 것 |
| 게임별 항목·값·기본값 | [05_games.md](./05_games.md) | 각 게임 접두사의 설정 기능이 자기 항목을 등재한다 |
| 값이 판정에 쓰이는 방식 | [../05_game_rules](../05_game_rules/README.md) | 판정 알고리즘·경계값·종료 증명 |
| 값의 타입·범위 규격 | [../07_api](../07_api/README.md) | 설정 규격과 검증 응답 |

**방 생성 시 설정**(방 제목·정원)은 이 도메인이 아니라 [01_room_join.md](./01_room_join.md)에 있다. 게임마다 바뀌는 값이 아니기 때문이다.

## 주제 템플릿 계열

주제는 이 판이 **무엇을 정하는 판인지** 설명하는 문구이며 게임마다 필요한 형태가 다르다. 계열은 4종이다.

| 계열 | 형태 | 쓰는 게임 |
|------|------|-----------|
| 사람 1명을 정하는 주제 | 짧은 명사구 | 운명의 룰렛 · 시간초 잡기 · 눈치게임 |
| 역할 목록 세트 | 항목 여러 개를 한 번에 채우는 세트 | 사다리타기 |
| 안건 주제 | 무엇에 대한 아이디어를 모을지 | 킹메이커 |
| 질문 문장 | 문장형이라 길이 상한이 따로다 | 익명 저격 |

- 계열별 칩 문구와 길이 상한의 값 정본은 [../03_requirements/README.md](../03_requirements/README.md)의 해당 도메인 문서다.
- 사다리타기만 주제가 **항목 목록**이며 세트를 고르면 항목이 한 번에 채워진다. 항목 수를 인원에 맞추는 동작은 F-LADDER-02가 담당한다.

## 게임 시작 조건

F-SETUP-11이 시작을 허용하기 전에 검사하는 조건이다. 하나라도 어긋나면 시작하지 않고 이유를 보인다.

| 조건 | 판정 | 실패 코드 |
|------|------|-----------|
| 요청자가 방장인가 | 서버가 보관한 방장 식별자와 대조 | member.not_host |
| 방 상태가 대기인가 | 방 상태머신 | game.invalid_action |
| 게임이 선택되었는가 | 선택 값 존재 | game.invalid_action |
| 현재 인원이 최소 인원 이상인가 | 활성 참가자 수 대조 | game.not_enough_members |
| 방장 제외 참가자 전원이 준비 완료인가 | 서버가 센 준비 수 | game.invalid_action |
| 설정값이 규격에 맞는가 | 설정 규격 재검증(F-SETUP-10) | game.invalid_config |

시작이 확정되면 순서대로 일어난다 — **명단 스냅샷 고정 → 새 라운드 식별자 발급 → 방 상태를 진행으로 전환 → 전원에게 시작 통지**. 이 순서를 지켜야 시작 직후 도착한 입장 요청이 확실히 거절된다.

## 가이드 노출 규칙

| 상황 | 가이드 |
|------|:------:|
| 게임 첫 시작 | 띄운다 |
| 게임 중 사용자가 다시 열기 | 띄운다 |
| 다시 하기 | 띄우지 않는다 |
| 결선 투표·동점자 재대결 | 띄우지 않는다 |
| 무효 라운드 재시작 | 띄우지 않는다 |

이미 규칙을 아는 사람에게 같은 화면을 반복해 보여주지 않되, **모르는 사람이 첫 판을 날리지 않도록** 첫 시작에는 반드시 띄운다.

## 에러 코드

| 코드 | HTTP | 발생 조건 |
|------|:----:|-----------|
| member.not_host | 403 | 참가자가 게임 선택·랜덤 선택·설정 변경·시작을 시도(F-SETUP-03·04·08·11) |
| game.not_enough_members | 400 | 현재 인원이 게임 최소 인원 미만(F-SETUP-02·11) |
| game.invalid_config | 400 | 설정 항목·타입·범위 위반, 대상 게임 불일치(F-SETUP-06·10) |
| game.invalid_action | 400 | 방 상태가 대기가 아닌데 선택·설정·시작을 시도(F-SETUP-11) |
| common.validation_failed | 400 | 주제 문자열 등 입력 스키마 위반(F-SETUP-06) |

전수·최종 채번 정본은 [../10_glossary/02_error_codes.md](../10_glossary/02_error_codes.md)다.

## 구현 정정 대상

| 지점 | 현행 구현 | 명세 |
|------|-----------|------|
| 설정 동기화 | 설정이 브라우저 상태에만 있어 방장 화면 밖으로 나가지 않는다 | F-SETUP-08 |
| 랜덤 선택 | 클라이언트가 뽑는다 | F-SETUP-04는 서버가 뽑아 전원에게 같은 값을 내린다 |
| 주제 직접 입력 | 길이 상한이 명세와 다르고 익명 저격에는 직접 입력 표면이 없다 | F-SETUP-06 |
| 설정 항목 누락 | 익명 저격의 투표 시간에 조작 표면이 없고, 눈치게임의 라운드 제한 시간이 코드에 고정돼 있다 | F-SETUP-07 · F-SNIPE-01 · F-NUNCHI-01 |
| 표시 전용 설정 | 킹메이커 1인 투표 수와 익명 저격 중복 투표가 화면에만 있고 판정에 쓰이지 않는다 | F-SETUP-07 · F-KING-01 · F-SNIPE-01 |
| 가이드 | 사용자가 닫을 때까지 떠 있고 게임별 "다시 보지 않기"로 억제된다 | F-SETUP-12는 첫 시작에 자동으로 띄우고 재시작 경로에서만 생략한다 |
| 게임 시작 | 명단 스냅샷·라운드 발급·입장 차단이 없다 | F-SETUP-11 |
