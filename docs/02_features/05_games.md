게임 6종은 각각 독립 접두사를 갖지만 파일은 하나로 묶는다 — 6개 문서에 나누면 같은 형태의 표가 여섯 번 반복되고, 게임 사이의 대칭(설정 → 입력 → 판정 → 연출)이 보이지 않기 때문이다. **게임 규칙 자체는 기능이 아니다.** 이 문서는 사용자가 조작하는 표면(버튼·입력·설정·표시)에만 기능 ID를 붙이고, 서버가 화면 없이 수행하는 판정도 기능으로 잡되 레이어를 BE로 적고 화면이 없음을 명시한다. 규칙·판정 알고리즘·상태머신·종료 증명·경계값의 정본은 [../05_game_rules](../05_game_rules/README.md)다.

## WHEEL — 운명의 룰렛

참가자 전원이 동일한 크기의 조각을 하나씩 갖고, 서버가 먼저 정한 당첨자에서 룰렛이 멈춘다. 참가자는 조작하지 않고 지켜보며 **동점·미입력이 발생할 수 없는 유일한 게임**이다.

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |
|----|------|------|--------|:--------:|:----:|
| **F-WHEEL-01** | 룰렛 설정 | 주제 하나를 정한다. 사람 1명을 정하는 주제 계열을 쓴다 | FE·BE | P1 | 🔶 |
| **F-WHEEL-02** | 조각 배치·내 조각 강조 | 참가자 수만큼 동일 확률 조각을 **입장 순서로** 배치하고 각자 자기 조각을 강조해 보여준다 | FE | P0 | 🔶 |
| **F-WHEEL-03** | PICK 실행 | 방장이 추첨을 실행한다. 참가자에게는 버튼이 없고 최초 1회만 인정한다 | FE·RT | P0 | 🔶 |
| **F-WHEEL-04** | 당첨자·시드 확정 | 서버가 당첨자와 난수 시드를 **연출보다 먼저** 정하고 그 결과를 전원에게 보낸다. **화면 없음** | BE | P0 | ⬜ |
| **F-WHEEL-05** | 회전 연출 수렴 | 룰렛이 정해진 시간 동안 돌다가 서버가 지정한 조각에서 멈춘다. 연출이 결과를 바꾸지 않는다 | FE | P0 | 🔶 |

## LADDER — 사다리타기

세로선 수·도착 항목 수를 **참가자 수와 같게 강제**해 1:1 배정을 보장한다. 참가자는 레인을 고르지 않고 입장 순서대로 자동 배치되며, 전원의 경로가 동시에 그려진다.

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |
|----|------|------|--------|:--------:|:----:|
| **F-LADDER-01** | 사다리 설정 | 도착 항목 목록(세트 선택 또는 직접 편집)과 진행 속도 3단을 정한다. 속도는 연출 길이만 바꾸고 결과에 영향을 주지 않는다 | FE·BE | P1 | 🔶 |
| **F-LADDER-02** | 항목 수 자동 맞춤 | 항목이 참가자보다 적으면 빈 항목으로 채우고 많으면 뒤에서부터 잘라낸 뒤, 어떻게 맞춰졌는지 방장에게 보여준다 | FE·BE | P0 | 🔶 |
| **F-LADDER-03** | START 실행 | 방장이 사다리를 시작한다. 참가자에게는 버튼이 없고 최초 1회만 인정한다 | FE·RT | P0 | 🔶 |
| **F-LADDER-04** | 사다리 구조 생성 | 서버가 가로선 배치를 만든다. 인접한 두 세로선 사이에만 놓고 같은 높이에서 겹치지 않게 한다. **화면 없음** | BE | P0 | ⬜ |
| **F-LADDER-05** | 경로 계산·배정 확정 | 참가자별 최종 도착 항목을 확정하고 서로 다른 참가자가 같은 항목에 도착하지 않음을 보장한다. **화면 없음** | BE | P0 | ⬜ |
| **F-LADDER-06** | 레인 자동 배치 표시 | 위에는 참가자, 아래에는 도착 항목을 같은 개수로 놓고 참가자가 입장 순서로 배치됐음을 보인다 | FE | P1 | 🔶 |
| **F-LADDER-07** | 동시 경로 연출 | 전원의 경로를 한꺼번에 그린다. 참가자별 고유 색으로 구분하고 가로선을 만나면 반드시 꺾는다 | FE | P0 | 🔶 |

## KING — 킹메이커

사람이 아니라 **아이디어**를 정하는 유일한 게임이다. 익명 제출 → 셔플 공개 → 투표 → 개표 순으로 진행하며, 안건을 내지 않은 사람도 투표한다.

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |
|----|------|------|--------|:--------:|:----:|
| **F-KING-01** | 킹메이커 설정 | 주제·1인 투표 수·결과 실명 공개 여부를 정한다 | FE·BE | P1 | 🔶 |
| **F-KING-02** | 안건 제출 | 제한 시간 안에 안건을 **익명으로 1인 1건** 낸다. 길이 상한이 있고 제출한 뒤에는 수정·취소할 수 없다 | FE·RT | P0 | 🔶 |
| **F-KING-03** | 안건 셔플 공개 | 제출 마감 후 작성자 정보를 뺀 채 순서를 섞어 공개한다. 제출 순서로 작성자를 추정할 수 없게 한다. **화면 없음** | BE | P0 | ⬜ |
| **F-KING-04** | 안건 투표 | 제한 시간 안에 안건을 고른다. **자기 안건은 고를 수 없고** 허용 표 수를 넘기면 거절하며 2표 이상이면 서로 다른 안건에만 나눠 준다 | FE·RT | P0 | 🔶 |
| **F-KING-05** | 미제출자 투표권 | 안건을 내지 않은 사람에게도 투표권을 준다. 제출은 권리이지 투표의 조건이 아니다. **화면 없음** | BE | P1 | ⬜ |
| **F-KING-06** | 개표·확정 | 안건별 득표를 세어 많은 순으로 정렬하고 최다 득표 안건을 확정한다. **화면 없음** | BE | P0 | ⬜ |
| **F-KING-07** | 결선 투표 | 최다 득표가 동점이면 동점 안건만 남기고 표를 초기화해 짧은 결선을 진행한다. 후보를 다시 제출하지 않으며 **최대 3회**다 | FE·BE·RT | P0 | 🔶 |
| **F-KING-08** | 안건 0건·1건 예외 | 안건이 0건이면 게임을 성립시킬 수 없으므로 설정 화면으로 되돌리고, 1건이면 투표를 건너뛰고 그 안건으로 확정한다. **화면 없음** | BE | P1 | ⬜ |
| **F-KING-09** | 제출자 실명 공개 | 설정이 실명일 때만, 그것도 **개표 후에만** 제출자를 드러낸다. 익명이면 끝까지 공개하지 않는다 | FE·BE | P1 | 🔶 |

## TIMER — 시간초 잡기

각자 자기 타이머를 시작하고 목표 시간이라고 느낀 순간 멈춘다. 숫자는 잠깐만 보이고 이후 가려진다. 오차로 순위를 매기며 **판정 기준을 방장이 뒤집을 수 있다.**

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |
|----|------|------|--------|:--------:|:----:|
| **F-TIMER-01** | 시간초 설정 | 주제·목표 시간·판정 기준(가장 가까운 사람·가장 먼 사람)을 정한다 | FE·BE | P1 | 🔶 |
| **F-TIMER-02** | START·개별 타이머 | 참가자별 독립 타이머를 시작한다. 다른 사람의 진행과 무관하게 흐르며 최초 1회만 인정한다 | FE·RT | P0 | 🔶 |
| **F-TIMER-03** | 숫자 블라인드 | 시작 후 짧은 시간만 숫자를 보여주고 이후 가린다. 감으로만 누르게 하기 위해서다 | FE | P0 | ✅ |
| **F-TIMER-04** | STOP 확정 | 최초 1회만 인정하고 즉시 확정한다. 되돌릴 수 없다 | FE·RT | P0 | 🔶 |
| **F-TIMER-05** | 정지 시간 산출·검증 | 클라이언트 단조 시계가 잰 경과 시간을 받아 서버가 관측한 시작·정지 도착 시각 차이로 허용 범위를 검증한다. **범위 밖이면 거부한다.** 전역 불변식의 유일한 예외이며 **화면 없음** | BE | P0 | ⬜ |
| **F-TIMER-06** | 오차 계산·순위 산출 | 절대 오차(판정용)와 부호 포함 시간 차이(표시용)를 정수 밀리초로 산출해 순위를 낸다. 판정 기준에 따라 최소 또는 최대가 뽑힌다. **화면 없음** | BE | P0 | ⬜ |
| **F-TIMER-07** | 마감 처리 | 시작 지연 상한 초과와 정지 제한 시간 초과를 각각 최하위로 처리하고 마감 후 도착한 정지 입력은 버린다. **화면 없음** | BE | P0 | ⬜ |
| **F-TIMER-08** | 동점자 재대결 | 절대 오차가 밀리초까지 같으면 동점자끼리 같은 목표 시간으로 다시 진행한다. **최대 3회**이며 초과하면 방장이 고른다 | FE·BE·RT | P1 | ⬜ |

## SNIPE — 익명 저격

질문 하나를 던지고 각자 한 명을 익명으로 지목한다. **자기 자신은 후보에 나타나지 않으며 지목할 수 없다.** 지목자를 드러낼지는 방장이 정한다.

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |
|----|------|------|--------|:--------:|:----:|
| **F-SNIPE-01** | 저격 설정 | 질문 주제·투표 시간·중복 투표 허용·지목자 공개 여부를 정한다. 투표 시간은 범위 안에서 직접 입력할 수 있다 | FE·BE | P1 | 🔶 |
| **F-SNIPE-02** | 후보 목록 | 자기 자신을 제외한 참가자만 후보로 노출한다. 목록의 정본은 명단 스냅샷이다 | FE·BE | P0 | 🔶 |
| **F-SNIPE-03** | 지목 제출 | 중복 투표 설정에 따라 1명 또는 여러 명을 지목한다. 허용 표 수를 넘기면 거절한다 | FE·RT | P0 | 🔶 |
| **F-SNIPE-04** | 자기 지목 거절 | 화면에서 자기 자신을 감추는 것과 별개로 서버가 자기 지목을 다시 검사해 거절한다. **화면 없음** | BE | P0 | ⬜ |
| **F-SNIPE-05** | 피격 집계·확정 | 후보별 피격 수를 세고 최다 득표자를 확정한다. **화면 없음** | BE | P0 | ⬜ |
| **F-SNIPE-06** | 결선 재투표 | 최다 득표가 동점이면 동점자만 후보로 남기고 **전원이** 다시 투표한다. **최대 3회**이며 초과하면 방장이 고른다 | FE·BE·RT | P0 | 🔶 |

| **F-SNIPE-08** | 지목선 연출·마스킹 | 지목선이 후보에게 뻗어 나가는 연출을 그린다. 지목자 공개가 비공개면 **선의 출발점을 가리고 피격 수만** 보여준다 | FE | P1 | 🔶 |

## NUNCHI — 눈치게임

**혼자 누를수록 유리한 구조다.** 혼자 누른 사람은 안전 확정되어 후보에서 빠지고, 판정창 안에 겹쳐 누른 사람과 아예 누르지 않은 사람이 남아 다음 라운드로 간다. 마지막 한 명이 뽑힌다.

| ID | 기능 | 설명 | 레이어 | 우선순위 | 상태 |

## 판정 결과의 뜻

같은 "뽑힘"이라도 게임마다 의미가 반대일 수 있어 결과 데이터의 해석을 한자리에 못박는다.

| 게임 | 확정 대상 | 뽑힌 사람의 뜻 |
|------|-----------|----------------|
| 운명의 룰렛 | 조각 1개 | 주제가 가리키는 역할을 맡는다 |
| 사다리타기 | 참가자 ↔ 항목 1:1 | 각자 도착한 항목이 자기 역할이다. 빈 항목을 받으면 배정된 역할이 없다 |
| 킹메이커 | 안건 1개 | 그 안건으로 정해진다. 사람이 아니다 |
| 시간초 잡기 | 사람 1인 | 판정 기준에 따라 오차가 가장 작거나 가장 큰 사람이다 |
| 익명 저격 | 사람 1인 | 가장 많이 지목된 사람이다 |
| 눈치게임 | 사람 1인 | **마지막까지 안전 확정하지 못한 사람**이다. 안전 확정은 빠져나간 것이고 남는 것이 뽑히는 것이다 |

## 구현 정정 대상

| 게임 | 현행 구현 | 명세 |
|------|-----------|------|
| 전 게임 | 결과를 브라우저 난수로 만들고 다른 참가자는 시간차로 움직이는 봇이다 | F-PLAY-01이 서버 확정이다 |
| 룰렛 | 자기 조각 강조가 없다 | F-WHEEL-02 |
| 사다리 | 항목이 참가자보다 적으면 남는 참가자에게 배정 없음을 주고, 항목 편집 입력 자체를 인원 수로 막는다 | F-LADDER-02는 빈 항목으로 채우고 초과분은 뒤에서 잘라낸다 |
| 킹메이커 | 1인 투표 수 설정이 화면에만 있고 실제로는 1표만 기록한 뒤 잠긴다 | F-KING-01 · F-KING-04 |
| 킹메이커 | 제출·투표 카운트다운이 0이 되어도 아무 일도 일어나지 않는다 | F-PLAY-05 · F-PLAY-09 |
| 킹메이커 | 결선 재투표에 상한이 없다 | F-KING-07(최대 3회) |
| 시간초 | 절대 오차가 같을 때 처리가 없어 목록 순서가 승자를 가른다 | F-TIMER-08 |
| 시간초 | 시작 지연 상한이 없다 | F-TIMER-07 |
| 저격 | 중복 투표 설정이 화면에만 있고 판정에 쓰이지 않으며, 투표 시간에 조작 표면이 없고, 질문 직접 입력이 없다 | F-SNIPE-01 |
| 저격 | 결선 재투표에 상한이 없다 | F-SNIPE-06(최대 3회) |
| 저격 | 지목자 공개 설정과 마스킹 연출이 없다 | F-SNIPE-01 · F-SNIPE-08 |
| 눈치 | **판정이 명세와 반대다.** 혼자 누른 사람이 후보로 남고, 겹쳐 누른 사람과 누르지 않은 사람이 후보에서 빠지며, 마지막 남은 사람이 스스로 눌러야 확정된다 | F-NUNCHI-05는 혼자 누르면 **안전 확정**이고 겹친 사람·미입력자가 남는다. F-NUNCHI-06은 추가 입력을 요구하지 않는다 |
| 눈치 | 라운드 제한 시간이 코드에 고정돼 설정 표면이 없다 | F-NUNCHI-01 |
| 눈치 | 아무도 빠지지 못한 라운드에서 마지막 입력자를 후보에서 뺀다 | F-NUNCHI-07이 무효 라운드로 보고 방장에게 묻는다 |

frontend/src의 눈치게임 판정 뒤집힘은 **게임이 성립하지 않는 결함**이다 — 혼자 누르는 것이 불리해지면 일부러 겹치는 편이 이득이 되어 눈치를 볼 이유가 사라진다. 정정 항목의 등재 정본은 [../01_overview/05_priorities_roadmap.md](../01_overview/05_priorities_roadmap.md)다.
