# ModuPick — 웹 디자인 구현 (첫 발표용 데모)

`docs/draft_design` **NEO-BRUTALIST v1 규격 시트 13장**을 정본으로 구현한 프론트엔드 데모입니다.
백엔드 없이 **봇 참가자 5인**(서연·민준·하늘·도윤·유진)이 입장·채팅·준비·게임 입력을 실시간처럼 시뮬레이션합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 프로덕션 빌드 (tsc + vite)
```

## 구현 범위

| 화면 | 내용 |

| S-04 대기방 | 3컬럼(참가자·채팅·게임 선택/설정) · C-05 설정 패널 6종 · 강퇴/랜덤/시작 |

## 발표 팁

- 화면은 **1920×1080 고정 스테이지**를 브라우저 크기에 맞춰 자동 스케일합니다(프로젝터 대응).
- 대기방에서 **`R` 키** = 봇 전원 준비 완료 (대기 시간 단축용 데모 보조).
- 표지 코드 입력에 `427132` → "이미 진행중인 방" 예외 연출을 보여줄 수 있습니다.
